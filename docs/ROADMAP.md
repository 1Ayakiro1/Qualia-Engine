# Роадмап

## v0.1.0 — skeleton (текущая)
- [x] Flutter-оболочка: 10 экранов, 3 режима
- [x] C++-ядро: worker + lock-free очереди + конвейер 6 модулей
- [x] FFI-мост, E2E-сессия, live-метрики
- [x] Спектрограмма-демо (STFT в Dart)
- [x] AppImage + tar.gz + бинарник, CI (Linux/Windows/macOS)

## v0.2 — HAL и хранилище
- Device Manager + HAL (первая плата / LSL-источник)
- Storage Service: локальные сессии, история
- Спектрограмма на данных ядра (перенос STFT в C++)
- Параметры модулей (set_param API) + JSON-конфиги
- macOS: интеграция ядра в Xcode-проект

## v0.3 — исследовательский минимум
- Сессии-записи: старт/стоп/пауза, разметка, экспорт
- Event/Marker System (шина событий, ERP-заготовка)
- Импорт датасетов (EDF/CSV), сравнение сессий
- Загрузка пользовательских модулей (песочница v1)

## v0.4 — модели и режимы
- Model Registry & Runtime (ONNX), обучение без кода (прототип)
- Права: личный/медицинский подрежимы, журналирование
- Топокарты, базовая 3D-визуализация

## v1.0 — API и синхронизация
- REST + WebSocket API для внешних сервисов
- Postgres/Supabase: метаданные, синхронизация
- Off-line first гарантии, multi-device
