# Готовые сборки

Папка для пользователей: здесь лежат свежие готовые сборки приложения,
которые можно запустить без сборочной цепочки. Содержимое обновляется при
каждом `./scripts/build_all.sh`; именно этот каталог используется для
публикации бинарников и релизных артефактов.

## Актуальная версия: 0.4.6

Добавлены оффлайн C++-модули `.qmod`: четыре действия в Explorer, локальный SDK
с примером и отдельный процесс на каждый узел. Параметры, события кнопок,
результаты и порты работают через host IPC; окна используют тот же экземпляр.
Инструкция: `docs/LOCAL_MODULES.md`. Нативные модули требуют явного доверия:
отдельный процесс не является защитной песочницей.
Готовый пример для установки через «Добавить локально»:
`modules/local-gain-0.1.0.qmod`.

Основной файл запуска на Linux: **`Ayakiro_BCI_Engine-0.4.6-x86_64.AppImage`**.
Он содержит интерфейс и ядро; дополнительные папки для его запуска не нужны.

```bash
./builds/Ayakiro_BCI_Engine-0.4.6-x86_64.AppImage
```

Также доступны portable-архив `Ayakiro_BCI_Engine-0.4.6-linux-x64.tar.gz`
и готовый распакованный bundle `binary/`. В каталоге оставлена только свежая
сборка; старые версии и резервные копии удалены.

Обновлённый Workspace: компактные Add / Select / View,
кнопка правой панели, выделение рамкой и панорамирование через Space / Alt + ЛКМ
или среднюю кнопку мыши. Переключатель `user&dev switcher` убран с рейла.
ПКМ по свободному канвасу открывает поиск модулей над Add; для узлов доступны
цвет заголовка, выбор узлов по цвету и фильтр View. Цвета сохраняются в графе.
Перетаскивание из Explorer больше не перекрывает канвас панелью или размытием.
Цвет подсветки каждого input/output выбирается через ПКМ по порту или Inspector
и сохраняется в графе; вся строка порта доступна для клика и соединения.
Линии связей наследуют цвета портов: градиент между разными цветами,
однотонная линия между одинаковыми и серая без подсветки. ПКМ по порту:
Название → Значение → Цвет; подменю открываются наведением или клавишей →.
Названия и типы значений сохраняются отдельно от авторских параметров;
переименование не разрывает связи. Для локальных C++-модулей тип входа также
проверяется при маршрутизации данных.
Input/Output и маркеры портов теперь прямоугольные со скруглениями,
строка категории/версии убрана из узла канваса.
Промежуточные точки сетки плавно появляются/исчезают при масштабировании.
Добавлены клавиатурная навигация Tab / Shift+Tab, Enter / Space для кнопок,
стрелки для меню и Esc для закрытия, с видимым фокусом и пропуском
отключённых действий. Контекстное меню узла/порта доступно через Shift+F10.
В Settings оставлен только Navigation / Навигация, без вкладки Keyboard shortcuts.
Сочетания можно изменять: захват клавиш, проверка конфликтов, сохранение и сброс.
Рамка фокуса появляется только при навигации клавишами и скрывается при использовании
мыши/тачпада; выделение графа при этом сохраняется.
Кнопка Workspace над канвасом переключает независимые проекты и открывает менеджер:
создание, переименование/описание, удаление, импорт/экспорт и отправка в Marketplace.
В каталоге есть Workspaces; онлайн-обмен требует отдельного развёртывания миграции
`20261003122742_workspace_catalog.sql` и модерации публикаций. Импорт подгружает
доступные точные версии metadata; для локальных C++-зависимостей требуется
предварительная установка соответствующего `.qmod`.
Inspector оформлен общими panel-блоками: экземпляр, параметры, оформление,
порты и соединения; шапка закреплена, секции сворачиваются.
Активную область модуля можно открыть на весь экран (F11, выход — Esc/F11)
или вынести в отдельное нативное окно. Отдельное окно также открывается
кнопкой в узле канваса, из Inspector и контекстного меню.
Параметры синхронизируются с Workspace; повторное открытие фокусирует
уже существующее окно экземпляра. Закрытие окна не удаляет модуль.
Клавиатурный zoom канваса доступен при наведении без предварительного клика.
Исправлено заполнение окна интерфейсом при масштабе 80% и ниже.
В контекстном поиске Add скрывается при вводе запроса; пустая выдача показывает
локализованное сообщение об отсутствии результатов.
Тачпад: прокрутка двумя пальцами двигает доску по обеим осям, pinch меняет
масштаб. Зажатое колёсико + движение мыши — панорамирование без Space;
Ctrl + прокрутка — масштабирование.

Marketplace Grid теперь использует masonry-раскладку: высота карточек зависит
от текста нижней части, колонки заполняются без ровных рядов. Все обложки
сохраняют пропорции 16:9; лицензия выбирается из выпадающего списка.
Заголовок License выровнен по размеру, жирности и отступам с остальными фильтрами.
Крупные шаги колёсика в каталоге, фильтрах, Explorer и debug log сглаживаются
короткой анимацией; мелкие precision-scroll события остаются прямыми.
Оптимизированы перерисовки Workspace и групповое перемещение узлов.
Linux-сборка включает custom Flutter GTK embedder с native-vsync bridge.
Кадры синхронизируются с GTK frame clock окна, без фиксированного лимита 60 FPS
или таймера 144 Гц. Частота следует timings системы, включая 144 Гц, если этот
режим действительно предоставляется GTK/compositor. Стабильные 144 FPS зависят
также от CPU/GPU. Для диагностики старого пути: `QUALIA_NATIVE_VSYNC=0`.
Подробнее и ограничения X11/Wayland: `docs/PERFORMANCE.md`.

| Файл | Что это |
|---|---|
| `Ayakiro_BCI_Engine-<версия>-x86_64.AppImage` | портативный запуск на Linux (один файл) |
| `Ayakiro_BCI_Engine-<версия>-linux-x64.tar.gz` | portable-архив того же бандла |
| `binary/` | **бинарник целиком**: `./bci_engine` + `lib/` + `data/` — запуск без распаковки |

```bash
# AppImage
chmod +x Ayakiro_BCI_Engine-*.AppImage && ./Ayakiro_BCI_Engine-*.AppImage

# portable bundle (бинарник + lib/ + data/)
./binary/bci_engine
```

Windows (`*.zip`) и macOS складываются сюда же из CI-сборок.
Каталог `dist/` больше не используется: сборка и запуск выполняются через
`builds/`.
